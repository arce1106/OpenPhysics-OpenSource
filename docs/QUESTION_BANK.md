# 完整目录、知识点示例与题库扩充

本仓库保留题目、选项、知识点、标签、公式、图片、审核状态、导入接口和数据库迁移。内置必修三册、选择性必修三册的完整目录，共 27 章、126 节、574 个知识点条目；巩固提升按完整教材目录浏览，高考复习包含六个知识板块、19 个专题及知识点映射。

每个知识点至少附一道 AI 原创演示题，共 586 道。第一章原有 20 道示例题保留；新增 566 道基础概念判断题，均有答案、解析及主要知识点标签，判断选项采用单选格式以复用客观题判分。新增题中正确、错误说法各 283 道。学习卡片仍只提供第一章的 8 张，配一张原创位置—时间图像，其余知识卡与教学正文由部署者补充。

这些题目未转录原教材或商业题库，用于体验目录、选题、作答和判分，不是完整章节练习册。高考专题映射可选到基础演示题，但这些题不能替代正式的高考分层题库。题目以已批准状态导入，便于演示；该状态不代表教师审定，正式教学前须由教师逐题复核。

目录不再依赖是否已有题目。将来扩展出的空知识点仍保留目录并显示“内容待补充”；练习推荐只使用有已批准主要知识点题目的条目。

## 数据位置

| 文件/目录 | 用途 |
| --- | --- |
| `backend/data/demo/chapter01.json` | 第一章原有 20 道示例题 |
| `backend/data/demo/knowledge-point-examples.json` | 其余 566 个知识点各一道原创概念判断题、答案与解析 |
| `backend/app/seed/knowledge_points.json` | 六册完整目录与知识点条目 |
| `backend/app/seed/knowledge_cards.json` | 学习卡片 |
| `backend/app/seed/learning_catalogs.json` | 学习目录与专题映射 |
| `backend/static/questions/` | 题目配图 |

运行 `docker compose exec backend python -m app.seed.seed_demo` 导入完整目录、586 道示例题及第一章学习卡片；重复执行仅补充缺少的条目，保留已有知识点和同题号题目，不覆盖使用者修改。已部署的早期版本也可执行同一命令补齐目录与示例题。高考目录升级只停用符合旧默认标识的独立 `demo_motion` 节点，保留其数据与学习证据；仅对仍保持旧默认名称与配置的目录补入新默认配置，不覆盖部署者自建专题或自定义配置。

## AI 辅助录题

从原稿、AI 提示词到 JSON 草稿导入的完整方法见 [AI 辅助录题教程](AI_QUESTION_IMPORT.md)，并提供[可复制的草稿示例](examples/ai-question-draft.json)。自动整理后仍须核对原题、公式、图片和标签，再审核开放。

## 扩充方式

1. 在管理后台维护知识点，或按示例的知识点 JSON 格式准备自己的章、节与知识点并运行 `python -m app.seed.seed`。该脚本只新增，不自动覆盖既有知识点。
2. 按 `chapter01.json` 中 `questions` 的结构准备题目，为每题分配唯一 ID，补充 `stem_text`、`question_type`、`answer`、`explanation`、`options` 和 `labels`。
3. 知识点标签使用 `label_type=knowledge_point`，`label_id` 对应已有知识点 ID。题型、难度层、公式与图片按现有模型填写。
4. 通过已登录管理后台或受管理员认证保护的 `POST /api/admin/questions/batch-import` 导入，提交对象包含 `questions` 数组。题目可先设 `quality_status=draft`，复核后再批准。
5. 图片使用 `images[].ref` 引用你有权分发的文件。命令行导入可给 `QuestionImporter` 传入 `image_dir`；HTTP API 的 `image_dir` 是后端本机目录，不能填写浏览器电脑上的路径。
6. 导入后核对题目、选项、答案、公式、配图与知识点关联，确认学习端可正常展示后再供学生使用。

新增题库由部署者自己维护和备份。本仓库不从原运营服务下载题库，也不提供自动同步入口。源码许可不自动覆盖使用者后来加入的第三方教学内容。
